# Portafolio de Desarrollo de Software

Sitio web personal creado para presentar mis proyectos, habilidades y experiencia práctica en el desarrollo de software y soporte técnico.

## Descripción

El portafolio reúne proyectos web, sistemas de gestión y aplicaciones Android, mostrando sus principales funcionalidades y las tecnologías utilizadas en su desarrollo.

## Contenido

- **Proyectos web:** sitios web, aplicaciones interactivas y videojuegos.
- **Sistemas:** aplicaciones para la gestión de información y automatización de procesos.
- **Aplicaciones Android:** proyectos móviles desarrollados con Kotlin.
- **Habilidades:** tecnologías y herramientas que utilizo.
- **Experiencia práctica:** proyectos y actividades realizadas durante mi formación profesional.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub
- GitHub Pages
